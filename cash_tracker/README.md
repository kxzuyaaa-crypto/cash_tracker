# Cash Tracker

A simple offline cash and expense tracker built with HTML, CSS, and JavaScript.

## Features
- Add cash/income
- Add expenses
- Expense amount is optional to enter only when you actually record an expense; saving requires an amount for accurate balance calculations
- Transaction dates
- Current balance
- Total cash added
- Total expenses
- Automated recurring cash additions: daily, weekly, or monthly
- Dark mode
- Transaction filtering
- Delete transactions and automated additions
- LocalStorage: data stays in the browser on the device
- No external libraries or internet connection required

## How to run
Open `index.html` in a modern web browser.

## Notes
Automated cash additions are processed when the app is opened. If several scheduled dates have passed, the app records each due addition automatically.
